Export Excel

Unduh data SIA dalam format Microsoft Excel (.xlsx).

File Excel dapat dibuka dan diolah kembali melalui Microsoft Excel atau LibreOffice. Pastikan library Excel sudah termuat; fitur ini memerlukan koneksi internet saat pertama kali memuat halaman.
Export seluruh data

Berisi beberapa sheet: seluruh transaksi, rekap bulanan, rincian transaksi bulanan, dan audit trail.

Export khusus transaksi

Hanya mengunduh daftar transaksi beserta nilai bruto, pajak, realisasi, status verifikasi, dan informasi transfer.

Catatan penggunaan
• Export membuat salinan data, tidak menghapus atau mengubah data di aplikasi.
• Data yang diekspor berasal dari penyimpanan browser ini.
• Untuk backup rutin, simpan file hasil export di lokasi kantor yang memiliki akses terbatas.

Import Excel

Impor database lama, periksa hasilnya, lalu konfirmasi.

Mendukung .xlsx, .xls, dan .csv. Pembaca Excel dimuat dari CDN sehingga perlu internet saat menggunakan fitur ini. Data lama tidak ditimpa. Periksa hasil pemetaan karena format tanggal dan angka dari Excel dapat berbeda.

Checklist & Aturan

Checklist umum dapat disesuaikan untuk kebutuhan pemeriksaan.

Untuk setiap item, petugas dapat memilih Lengkap, Tidak Lengkap, atau Tidak Berlaku. Jika Tidak Berlaku, alasan dicatat pada catatan transaksi.
