Pemisah PDF Kwitansi

Upload satu file PDF yang berisi banyak kwitansi, lalu pisahkan menjadi file PDF tersendiri dengan nama sesuai keinginan, misalnya September_1 sampai September_100.

1. Upload file PDF

Klik di sini atau seret file PDF ke sini File diproses di browser Anda dan tidak diunggah ke server mana pun.

2. Cara memisahkan

Jika satu kwitansi memakai 2 halaman, isi "Halaman per file" dengan 2. Untuk 1 halaman = 1 kwitansi, biarkan 1.

3. Nama file

Gunakan {no} untuk nomor urut dan {bulan} untuk teks di atas. Ekstensi .pdf ditambahkan otomatis.

Baris yang terisi dipakai menggantikan pola, dan file sisanya tetap memakai pola di atas. Bisa ditempel langsung dari satu kolom Excel.

Upload PDF untuk melihat contoh nama file.

4. Unduh

Setelah ZIP terunduh, ekstrak untuk mendapatkan file-file PDF terpisah.
